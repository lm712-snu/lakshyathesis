# Mathematics of Computer Vision Language Models

An interactive mathematical exploration of how images become language.

## Live Website

**https://lm712-snu.github.io/lakshyathesis/**

If GitHub Pages has not activated the link yet, open **Settings → Pages** in this repository and choose **GitHub Actions** as the deployment source. The repository already contains the Pages workflow.

## Topics

- Image → tensor mathematics
- Convolution and CNN feature extraction
- Image patches and patch embeddings
- Positional encoding
- Vision Transformers
- Self-attention
- Image-text alignment and contrastive learning
- Vision-to-language projection
- Cross-modal attention
- Next-token prediction
- Autoregressive generation
- Mathematical matrix sandbox
- Viva mode

Educational mathematical simulation for the thesis **“Mathematics of Computer Vision Language Models.”**
